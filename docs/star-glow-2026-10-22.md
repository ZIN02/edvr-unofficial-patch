# Star glow: a stronger bloom halo around stars, by star (2026-10-22)

## Status

- **State: DESIGN, NOT BUILT.** A user asked for the 2026-10-20 double
  bloom back (the HUD re-issue added T(bloom) over the frame), for stars
  only: 100 to 200% in steps of 25, 100 stock, then a strength per star.
- **Mechanism (planned):** at the bloom chain's first level, the HUD bloom
  feed's pass binds H' = H + HUD + sum over stars of (k_star - 1)·S_star.
  S_star is that star's draws replayed against the final depth, so the
  game's own bloom makes a stronger halo. Flat only; temporal AA on.

## Survey 2 instrument: the log lines and the reader

Still observe-only, still a Home census only. A constant buffer window with
no shadow is copied at its draw into a staging buffer of the dump's own
(`src=staging`, 128 buffers a census, the pool), and so is the vertex or
instance range each star draw reads (4096 bytes a range). The census end maps
them with a **blocking Map**: the CPU waits once for the GPU, on the press and
nowhere else. Windows are dumped whole up to 8192 bytes (b1 is 42 lines). A
window the pool or the context could not read says `src=none skipped=...`
(`pool-full`, `window-unknown`, `deferred-context`, `stage-failed`,
`map-failed`), and the `end` line counts each. Every new line carries
`frame=` (q repeats in each census frame).

| Line | Says |
|---|---|
| `flat star cb: census=3 frame=1 q=633 PS b2 src=staging map=blocking ... shadow=untracked-no-private-copy h=.. data=below` | one block; `src=shadow` was the CPU shadow; `same-bytes-as frame q VS b0` names an earlier identical block |
| `flat star ia: ... slot=1 stride=64 off=0 width=.. class=instance step=1 layout=known` | a bound vertex buffer and the input layout's class for the slot (`unknown`: both ranges are read) |
| `flat star vb: ... slot=1 kind=instance first=3 elems=85 off=192 bytes=4096 wanted=5440 range=capped` | the range read: indexed draws read the index count from the base vertex, an upper bound |
| `flat star geometry: ... star=1/2 d=578223364 R=280954976 R-src=b2 R-b0=280954977 d/R=2.05806 angular-radius=29.071deg ... draws=P0:q467(b),P4:q641(o)` | per star per pass; `(b)` shared b0, `(d)` ring direction, `(r)` radius, `(o)` draw order, `(s)` the only star |
| `flat star colour: ... rgb=1,0.278754,0.0630237 S=164.895 src=P4.psb2[0].yzw@+4 ... surface-peak=2.06765 chroma=agree` | peak-normalised colour and S; the surface's `P1.psb2[0].xyz@+0` beside it |
| `flat star exposure: ... b1[61].z@+984=865.16 b1[61].w@+988=429.439 b1[62].xyz@+992=..` | the exposure-like b1 values |
| `flat star scalars: ... P1.psb2[1].w@+28=0.120688 ... P5.vsb2[1].x@+16=0.088822` | the P1 surface scalars, and P2/P4/P5's star-varying ones |
| `flat star unassociated: ... draws=P3:q564(no-b0-link)` | draws no b0, ring or radius ties to a star (P3 and P2/P4 share a camera-attached b0) |

`python tools\star_survey.py [--file <edvr_gfx_*.log> ...] [--csv out.csv]`
decodes the hex itself (so the first survey's v1 log joins the dataset),
checks it against the DLL's own decoded lines in a v2 log, matches each engine
star to the `truth star` line by radius within 0.1%, and prints the per-star
tables, the best one- and two-variable fits with leave-one-out error (a
relation needs 3 stars, a pair 5) and the near/far series of one star.
`--dry-run` writes nothing. Its fixture, `tools\star_survey_fixture.log`, is
what the formatters write (regenerate: `flat_temporal_test.exe
--write-star-fixture <path>`).

## The setting (proposed)

`visual.star_glow` (decided 2026-10-22; first proposed as `fix.star_glow`),
with choices 100, 125, 150, 175 and 200 (100 the default, stock), plus a
second choice for how it applies: the same for every star, or by star.
Live; on the flat F8 panel's Visual tab and the installer. The per-star
weight comes from what the engine draws (decided), so the class table
below is superseded: it stays as the first sketch of the ordering. In the
by-class mode the setting is the peak: k = 1 + (peak - 1)·w(star).

| w | Classes |
|---|---|
| 1.0 | O, Wolf-Rayet, neutron |
| 0.85 | B |
| 0.75 | white dwarf |
| 0.65 | A, Herbig Ae/Be |
| 0.45 | F |
| 0.3 | G |
| 0.2 | K, T Tauri |
| 0.1-0.15 | M, carbon |
| 0 | brown dwarfs, black holes |

Luminosity classes I-III add 0.15. An unknown star stays at stock.
